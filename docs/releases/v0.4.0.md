# Tenet Commerce v0.4.0 — Release candidate

Status: release candidate prepared; tag and GitHub Release require explicit approval.

This candidate packages the verified online Phase 3 frontend integration on top of the Phase 2 backend, runtime operability, production frontend container, benchmark evidence, and portfolio quick start available on `develop`.

## Included

- Go API readiness/liveness endpoints, graceful shutdown, environment-controlled maintenance mode, and Compose runtime defaults.
- Next.js standalone production image running as a non-root user, with Compose healthcheck and internal BFF routing.
- Architecture decisions and implementation evidence for tenant scoping, idempotency recovery limits, inventory/QC, and public claim boundaries.
- Reproducible isolated benchmark harness with PostgreSQL 16 and Redis 7 fixtures, raw JSONL artifacts, and post-workload invariant checks.
- Clean-clone README path and portfolio showcase covering implemented capabilities and planned boundaries.

## Verification

The candidate commit is selected from `develop` after backend build/vet/race-short, frontend lint/test/build, benchmark fixture runs, Mermaid rendering, reconciliation queries, and Browser E2E checks recorded by the merged PRs. A clean-clone smoke and final tag verification remain release-gate actions.

## Known limits

- Offline paid transaction replay, AI auditing, Zakat calculation, and production availability orchestration remain planned; this is not a claim that all Phase 3 scope is complete.
- HTTP idempotency response persistence occurs after the business handler; crash recovery remains endpoint-specific.
- Benchmark figures measure an isolated laptop fixture and do not establish production capacity or SLA.
- Compose is a reproducible demo runtime; TLS, secrets management, and hosted operations are outside this candidate.
